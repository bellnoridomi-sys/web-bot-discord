Notice.

Trang này mô tả dữ liệu mà Aki Dev có thể xử lý khi bạn dùng dashboard hoặc thêm bot vào Discord server.

Dữ liệu được xử lý

  • Thông tin hồ sơ Discord và danh sách server được OAuth trả về nhằm hiển thị server mà tài khoản có thể quản lý.
  • ID server/người dùng, XP, xu ảo, cảnh cáo, case moderation, vouch, cờ cảnh báo scammer, nhắc việc và cấu hình automation khi tính năng tương ứng được dùng.
  • Hoạt động điều khiển từ web và lỗi runtime có thể được ghi vào kênh log do quản trị viên chọn.

Phiên đăng nhập

Dashboard dùng cookie phiên HttpOnly. Token OAuth cần thiết được mã hoá khi lưu phiên trong PostgreSQL; metadata phiên có thể được lưu để giữ đăng nhập sau khi service restart. Không gửi bot token hoặc secret qua dashboard.

Lưu giữ và xoá

Dữ liệu được giữ trong database của host cho đến khi quản trị viên xoá hoặc chính sách lưu giữ của tính năng áp dụng. Quản trị viên server nên dùng bản sao lưu an toàn và chỉ cấp quyền log cho staff phù hợp.

Chia sẻ với bên thứ ba

Đăng nhập dựa trên Discord OAuth; bot tương tác với Discord API để thực hiện tính năng được yêu cầu. Không bán dữ liệu cho quảng cáo. Không đưa token hoặc secret vào kênh công khai.
