03 / COMMANDS

26 tools.
No filler.

Slash commands đăng ký thật qua Discord HTTP API. Prefix alias `!` vẫn có cho các lệnh nhanh; AFK hỗ trợ thêm URL ảnh/GIF hoặc upload attachment.

AFK EXAMPLE/afk reason:đi ngủ image_url:https://example.com/anime.gif/afk reason:đi học media:<upload gif>Media được lưu theo từng server + user và xuất hiện trong embed khi member bị tag.
04 / DOCUMENTATION

Ship it.
Keep the aura.

Deploy từ GitHub lên Render, cắm credentials qua Environment Variables và giữ OAuth callback khớp với URL thật.

01

Discord Developer Portal

Tạo Application → Bot → lấy Token. Bật các intents đúng với bot. OAuth2 Redirect URI:

/auth/discord/callback
02

AFK Media

Gõ `/afk`, nhập reason rồi chọn image_url hoặc upload trực tiếp ở media. Khi người khác tag bạn, bot trả embed kèm hình/GIF.

03

Render

Blueprint tạo Web Service + Postgres cùng region. Web nghe trên 0.0.0.0:$PORT và có /health.

04

Reality check

Free Web Service của Render có thể sleep sau thời gian không có traffic; voice 24/7 cần plan không sleep.
