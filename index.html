04 / DOCUMENTATION

Ship it.
Safely.

Deploy từ GitHub lên Render, cắm credentials qua Environment Variables và dùng đúng callback OAuth.

01

Discord Developer Portal

Tạo Application → Bot → lấy Token. Bật Guilds / Guild Messages / Message Content / Guild Voice States theo cấu hình code. OAuth2 Redirect URI:

/auth/discord/callback
02

Google Cloud

Tạo OAuth Client loại Web application. Authorized redirect URI:

/auth/google/callback

Điền Client ID và Client Secret vào Render Environment.

03

Render

Dùng Blueprint render.yaml. Nó tạo Web Service + Postgres. Web app nghe trên 0.0.0.0:$PORT và có health check.

04

24/7 reality check

Free Web Service của Render sleep sau 15 phút không có inbound traffic. Muốn bot/voice chạy liên tục, chọn compute plan không sleep.

LOCAL

Start in 3 commands

cp .env.example .env
npm install
npm start
